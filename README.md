# Apocalypse Store – Power BI Project

## Overview

This project focuses on exploring and visualizing store sales data using Microsoft Power BI to derive meaningful business insights and understand various data analytics concepts.

## Objectives

- Analyze sales, revenue, and profitability.
- Understand product performance and sales trends.
- Develop interactive dashboards.
- Apply Power BI concepts through hands-on implementation.

## Concepts Applied

- Data Cleaning and Transformation using Power Query
- Data Modeling and Relationships
- DAX Measures and Calculated Columns
- SUM, SUMX, and other DAX Functions
- Filter Context and Row Context
- Interactive Data Visualization
- Dashboard Design and Reporting

## Tools Used

- Microsoft Power BI Desktop
- Power Query
- DAX

## Project Files

- `Apocalypse-Store.pbix` – Power BI dashboard and data model.
- `Screenshots/` – Dashboard visualizations.
