## 🚀 Projects

### 1. Global Airbnb Performance Dashboard

**Tools:** Power BI, Power Query, DAX

Developed an interactive dashboard to analyze Airbnb performance across major global cities, focusing on listing distribution, host performance, pricing, and guest satisfaction.

**Key Analysis:**
- Listing distribution across cities
- Superhost vs. non-Superhost analysis
- Average pricing by room type
- Guest ratings across different cities
- Cumulative reviewer analysis
- City-level performance comparisons

**Key Insights:**
- Paris recorded the highest listing volume among the cities analyzed.
- Hotel rooms had the highest average price among room types.
- Mexico City and Cape Town recorded the highest average guest ratings.
- Guest ratings remained consistently high across all cities.
- Superhost distribution varied significantly across cities.

**Concepts Practiced:**
- DAX measures and calculated columns
- `CALCULATE`, `FILTER`, `ALL`, `DISTINCTCOUNT`
- Cumulative calculations
- Data aggregation
- KPI cards
- Combo charts
- Bar charts and column charts
- Dashboard design and data storytelling
