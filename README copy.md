# Power BI Learning & Projects

A repository documenting my journey in **Power BI, data visualization, and business intelligence**. I use it to practice concepts, build dashboards, analyze datasets, and keep a record of what I learn.

## What this repository contains

- **Projects:** End-to-end Power BI reports and dataset-based analysis.
- **Learning notes:** Concepts, DAX patterns, Power Query workflows, and visualization techniques.
- **Dashboard insights:** Observations and takeaways from the reports I build.
- **Roadmap:** Topics I am learning next to strengthen my analytics skills.

## Projects

| Project | Focus | Tools / Concepts |
|---|---|---|
| Airbnb Data Visualization and Storytelling | Explore Airbnb listings, pricing, room types, host status, and ratings | Power BI, Power Query, DAX, data visualization |
| Melbourne House Price Prediction / Analysis | Explore Melbourne housing data and price-related patterns | Data analysis, visualization |
| Data Visualization Practice | Practice report design and visual analytics | Power BI, charts, slicers, KPIs |

> Project names and descriptions may be updated as each report evolves.

## Skills practiced

- **Power BI:** report building, visuals, cards, slicers, filters, formatting, and dashboard layout
- **Power Query:** data import, cleaning, transformation, and preparation
- **DAX:** measures, calculated columns, filter context, `CALCULATE`, `COUNTROWS`, `DISTINCTCOUNT`, `SUMX`, and cumulative calculations
- **Data analysis:** aggregations, comparisons, trends, distributions, and KPI analysis
- **Data storytelling:** turning dashboard results into clear, concise observations

## Example: Airbnb dashboard observations

Some observations explored in the Airbnb report:

- Paris has the largest listing count in the cities compared, followed by New York and Rome.
- Paris also has the highest absolute Superhost count among the cities in the report.
- Average prices differ by room type; Hotel Rooms are the most expensive on average, followed by Entire Places and Shared Rooms.
- Mexico City and Cape Town have among the highest average ratings in the comparison, while Hong Kong is lower.
- The ratings in the cities analyzed generally fall within a relatively narrow range.

These are dashboard-specific observations, not universal conclusions about Airbnb.
